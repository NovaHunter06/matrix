# Quasar.c | NOVA Protocol 🌌

An implementation of the **NOVA** terminal interface. This project explores terminal manipulation, timed delays, and custom display logic using C.

## 🛠️ Features
- **Hacker Aesthetic:** Custom "Nova" branding and messaging.
- **Typewriter Effect:** Real-time character rendering for a high-tech feel.
- **System Simulation:** Includes timed pauses and simulated system commands.

## 🚀 Installation & Usage

### 1. Requirements
You need a C compiler installed on your system (such as `GCC` or `Clang`).

### 2. Compilation
Open your terminal and run the following command to compile the source code:
```bash
gcc Quasar.c -o Quasar
